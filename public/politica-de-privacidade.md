# POLÍTICA DE PRIVACIDADE — LINK MÁGICO

**Última atualização:** 10 de Dezembro de 2025

---

## 1. INTRODUÇÃO

A sua privacidade é importante para nós. Esta Política de Privacidade descreve como o **Link Mágico** ("nós", "nosso" ou "Serviço") coleta, usa, armazena e protege suas informações pessoais em conformidade com a **Lei Geral de Proteção de Dados (LGPD)** — Lei nº 13.709/2018.

---

## 2. DADOS QUE COLETAMOS

### 2.1 Dados do Usuário (Contratante do Serviço)
- **Dados de identificação:** Nome, e-mail, telefone
- **Dados de pagamento:** Processados exclusivamente pela Hotmart
- **Dados de acesso:** API Key, logs de acesso, endereço IP

### 2.2 Dados dos Leads (Clientes do Usuário)
Quando você utiliza o Link Mágico em sua página, coletamos:
- **Dados fornecidos voluntariamente:** Nome, e-mail, telefone, mensagens do chat
- **Dados de navegação:** URL de origem, horário de acesso
- **Dados de conversa:** Histórico de mensagens com o assistente de IA

### 2.3 Dados Coletados Automaticamente
- **Cookies:** Para manter sessões e melhorar a experiência
- **Logs de servidor:** Endereço IP, tipo de navegador, páginas acessadas
- **Analytics:** Métricas de uso como número de conversas e leads capturados

---

## 3. COMO USAMOS SEUS DADOS

Utilizamos os dados coletados para:

| Finalidade | Base Legal (LGPD) |
|------------|-------------------|
| Prestação do Serviço contratado | Execução de contrato (Art. 7º, V) |
| Suporte técnico e atendimento | Execução de contrato (Art. 7º, V) |
| Envio de comunicações importantes | Legítimo interesse (Art. 7º, IX) |
| Melhoria do Serviço | Legítimo interesse (Art. 7º, IX) |
| Cumprimento de obrigações legais | Obrigação legal (Art. 7º, II) |
| Marketing (opcional) | Consentimento (Art. 7º, I) |

---

## 4. COMPARTILHAMENTO DE DADOS

### 4.1 Com Quem Compartilhamos
- **Hotmart:** Processamento de pagamentos
- **Provedores de infraestrutura:** Render (hospedagem), PostgreSQL (banco de dados), Redis (cache)
- **Provedores de IA:** OpenAI, Groq, OpenRouter (processamento de linguagem natural)

### 4.2 Não Compartilhamos
- Não vendemos seus dados para terceiros
- Não compartilhamos leads capturados com outros usuários
- Não utilizamos seus dados para publicidade de terceiros

---

## 5. ARMAZENAMENTO E SEGURANÇA

### 5.1 Onde Armazenamos
Os dados são armazenados em servidores seguros com:
- **Banco de dados PostgreSQL** criptografado
- **Conexões SSL/TLS** para transferência segura
- **Backups automáticos** diários

### 5.2 Medidas de Segurança
- Criptografia de dados sensíveis
- Autenticação por API Key única
- Sistema de detecção de ameaças (WAF)
- Rate limiting contra ataques de força bruta
- Validação rigorosa de entrada de dados

### 5.3 Tempo de Retenção
- **Dados de conta:** Enquanto a conta estiver ativa + 5 anos
- **Leads capturados:** Definido pelo Usuário (disponível para exclusão a qualquer momento)
- **Logs de sistema:** 90 dias

## 8. COOKIES

### 8.1 Cookies Essenciais
- **Sessão:** Manter você logado
- **Segurança:** Proteção contra CSRF

### 8.2 Cookies de Funcionalidade
- **Preferências:** Lembrar suas configurações
