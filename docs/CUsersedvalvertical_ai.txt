# BRIEFING OFICIAL — MODERNIZAÇÃO DA INTERFACE DO LINKMÁGICO V7

## Objetivo

Executar uma modernização completa da interface (UX/UI) do LinkMágico, elevando significativamente a percepção de qualidade, profissionalismo, simplicidade e fluidez da plataforma.

IMPORTANTE:

Esta tarefa NÃO é uma refatoração do sistema.

Esta tarefa NÃO é uma alteração da arquitetura.

Esta tarefa NÃO autoriza mudanças na lógica de negócio.

Esta tarefa NÃO deve modificar qualquer funcionalidade existente.

Todo o comportamento atual do sistema deve permanecer exatamente igual.

O objetivo é exclusivamente melhorar a experiência do usuário, organização visual e fluxo de utilização.

A plataforma já possui meses de desenvolvimento e diversas integrações críticas funcionando.

Portanto, qualquer alteração deve respeitar integralmente a implementação atual.

---

# REGRAS OBRIGATÓRIAS

• Não alterar APIs.

• Não alterar banco de dados.

• Não alterar estrutura das integrações.

• Não alterar rotas.

• Não alterar autenticação.

• Não alterar lógica do backend.

• Não alterar comportamento dos módulos existentes.

• Não remover nenhuma funcionalidade.

• Não alterar funcionamento do assistente IA.

O usuário deve conseguir criar seu primeiro vendedor automático com o menor esforço cognitivo possível.

• simplicidade

• velocidade

• profissionalismo
