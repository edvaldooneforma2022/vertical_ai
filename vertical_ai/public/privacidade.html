🔒 Política de Privacidade — LinkMágico

Última atualização: 30 de Maio de 2026

1. Introdução

Esta Política de Privacidade descreve como o LinkMágico (acessível em linkmagico.app.br) coleta, utiliza, armazena e protege seus dados pessoais, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

2. Dados que Coletamos

2.1 Dados do Titular da Conta (Usuário)

  • Nome — para identificação na plataforma
  • Email — para login, comunicações e recuperação de senha
  • Senha — armazenada com hash criptográfico (nunca em texto plano)
  • WhatsApp (opcional) — para suporte e notificações
  • Dados de pagamento — processados exclusivamente pela Stripe (não armazenamos dados de cartão)

2.2 Dados dos Visitantes/Leads (capturados pelo chatbot)

  • Nome, email e telefone (quando fornecidos voluntariamente na conversa)
  • Histórico de conversas com o chatbot
  • Dados de navegação (URL de origem, timestamps)

2.3 Dados Técnicos

  • Endereço IP (para segurança e rate limiting)
  • User-Agent do navegador
  • Cookies de sessão (essenciais para autenticação)

3. Como Usamos seus Dados

  • Prover e manter o funcionamento da plataforma
  • Processar pagamentos e gerenciar assinaturas
  • Enviar notificações relevantes sobre o serviço
  • Melhorar a experiência do usuário e funcionalidades
  • Cumprir obrigações legais e regulatórias
  • Prevenir fraudes e garantir a segurança do sistema

Importante: Seus dados nunca são vendidos, alugados ou compartilhados com terceiros para fins de marketing. Os dados dos leads capturados pelo chatbot pertencem exclusivamente ao titular da conta.

4. Compartilhamento de Dados

Compartilhamos dados apenas com:

  • Stripe — para processamento de pagamentos
  • Render — infraestrutura de hospedagem
  • Twilio/Evolution API — integração WhatsApp (quando ativada pelo usuário)
  • OpenAI — processamento de IA para geração de respostas do chatbot

Todos os parceiros acima possuem políticas de privacidade próprias e operam em conformidade com padrões internacionais de segurança.

5. Armazenamento e Segurança

  • Todos os dados são transmitidos via HTTPS/TLS
  • Senhas são armazenadas com hash bcrypt
  • Acesso ao banco de dados é restrito e protegido por autenticação
  • Sistema multi-tenant com isolamento de dados entre contas
  • Backups automáticos para recuperação de dados

6. Seus Direitos (LGPD)

Você tem direito a:

  • Acesso — solicitar cópia dos seus dados pessoais
  • Correção — atualizar dados incorretos ou incompletos
  • Exclusão — solicitar a remoção dos seus dados
  • Portabilidade — exportar seus dados em formato legível
  • Revogação de consentimento — retirar permissões a qualquer momento
  • Informação — saber com quem seus dados são compartilhados

Para exercer qualquer direito, entre em contato conosco pelos canais abaixo.

7. Cookies

Utilizamos apenas cookies essenciais para:

  • Manter sua sessão de login ativa
  • Lembrar preferências da plataforma
  • Garantir segurança (CSRF protection)

Não utilizamos cookies de rastreamento publicitário ou de terceiros.

8. Retenção de Dados

  • Dados da conta são mantidos enquanto a conta estiver ativa
  • Após cancelamento, dados são mantidos por 90 dias para possível reativação
  • Após 90 dias, dados são excluídos permanentemente, exceto quando exigido por lei
  • Logs de segurança são mantidos por 12 meses

9. Menores de Idade

O LinkMágico não é destinado a menores de 18 anos. Não coletamos intencionalmente dados de menores. Se tomarmos conhecimento de dados de menores, serão excluídos imediatamente.

10. Alterações nesta Política

Esta política pode ser atualizada periodicamente. Alterações significativas serão comunicadas por email ou pela plataforma. A data de atualização no topo desta página sempre reflete a versão vigente.
