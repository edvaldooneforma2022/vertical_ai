🚀 1. Introdução à Plataforma

O Link Mágico é uma plataforma SaaS revolucionária que permite criar chatbots superinteligentes para qualquer site em minutos. Com tecnologia de ponta em Inteligência Artificial Conversacional, o Link Mágico transforma visitantes em clientes através de interações naturais e personalizadas.

✨ O que torna o Link Mágico especial?

🧠

SuperInteligência Conversacional

IA avançada com detecção de emoções, sarcasmo, múltiplas intenções e memória conversacional.

⚡

Instalação em 5 Minutos

Basta adicionar uma linha de código JavaScript ao seu site e pronto!

🎯

Captura Inteligente de Leads

Sistema automatizado que coleta e qualifica leads durante as conversas.

👥 4. Sistema de Captura de Leads

O Link Mágico captura leads automaticamente durante as conversas, armazenando informações de contato e qualificando cada lead.

Figura 2: Painel de Gestão de Leads com exportação e backup

📋 Dados Capturados

Campo Descrição
Nome Nome do visitante
E-mail Endereço de e-mail
Telefone Número de telefone (opcional)
Mensagem Primeira mensagem ou interesse
URL de Origem Página onde foi capturado

🏷️ Classificação Automática

🔥 Hot (Quente)

Lead com e-mail E telefone. Alta probabilidade de conversão.

🌡️ Warm (Morno)

Lead com e-mail OU telefone. Potencial médio.

❄️ Cold (Frio)

Lead com dados básicos. Requer nutrição.

📤 Exportação e Backup

Exporte para CSV com um clique. Sistema de backup automático com opção de restauração.

🔧 8. Integração no Site

📋 Código de Integração

Adicione antes de </body>:

<!-- Link Mágico Widget --> <script src="https://vertical-ai-dktu.onrender.com/public/widget.js"></script> <script> LinkMagico.init({ apiKey: 'SUA-API-KEY', robotName: 'Assistente Virtual', instructions: 'Suas instruções aqui' }); </script>

⚙️ Parâmetros

Parâmetro Tipo Descrição
apiKey String (obrigatório) Sua chave de API
robotName String Nome do assistente
instructions String Instruções de comportamento
primaryColor String (hex) Cor principal

📡 9. Documentação da API

🔗 Endpoints Principais

Método Endpoint Descrição
POST /api/process-chat-inteligente Processa mensagens com IA
POST /api/capture-lead Captura dados de lead
GET /admin/leads Lista todos os leads
GET /api/appointments/:leadId Agendamentos de um lead
GET /api/system/status Status do sistema
GET /health Verificação de saúde

🔐 Autenticação

X-API-Key: SUA-API-KEY
